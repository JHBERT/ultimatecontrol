# UltimateControl 1.7.0 – CSDb-Ansicht

Neu ist der Tab **CSDb** in der Karte. Er zeigt die zwei Tabellen der
CSDb-Startseite:

- **Latest Releases** – die ersten fünf Einträge, ein Klick auf die Überschrift
  öffnet die ganze Liste (25 Releases mit Typ, Gruppe und Datum).
- **Top Demos** – die ersten fünf Plätze, ein Klick auf die Überschrift öffnet
  den kompletten Chart mit Gruppe, Rating und Stimmen.

Ein Klick auf eine Demo öffnet ihre Seite: Typ, Datum, Gruppe, Event und
Platzierung, Rating, Credits, verwendete SIDs, Download-Links und die neuesten
Kommentare. Oben links führt **‹ Zurück** eine Ebene zurück.

Ein Download lässt sich mit **⤓** in die Bibliothek entpacken
(`sids/csdb/<Release-ID>/`) und die entpackten Images mit **▶** direkt auf dem
C64 starten.

Die Listen werden fünf Minuten zwischengespeichert.

## Installation über HACS

1. HACS → UltimateControl → **Update** auf 1.7.0.
2. Home Assistant neu starten.
3. Seite hart neu laden (Strg+F5).
