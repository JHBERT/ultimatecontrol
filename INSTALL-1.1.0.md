## Was MIT für das Projekt bedeutet

**Erlaubt:** benutzen, verändern, weitergeben, in eigene Projekte einbauen,
auch kommerziell.

**Pflicht:** Copyright-Hinweis und Lizenztext beilegen, wenn jemand den Code
weitergibt.

**Nicht enthalten:** Gewährleistung oder Haftung – wer den Code nutzt, tut das
auf eigenes Risiko.

**Für HACS:** MIT ist die Lizenz, die HACS für Integrationen empfiehlt; die
Integration lässt sich damit auch in HACS-Default-Repositories aufnehmen.

**Für dich als Rechteinhaber:** du bleibst Urheber und kannst den Code
zusätzlich unter einer anderen Lizenz anbieten, wenn du willst.

## Installation über HACS

1. HACS → UltimateControl → **Update** auf 1.1.0.
2. Home Assistant neu starten.
3. Seite hart neu laden (Strg+F5).
