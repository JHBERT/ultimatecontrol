## UltimateControl 0.4.1

Die SID-Auswahl kommt als eigene Dashboard-Card, die die Integration selbst
ausliefert.

**Neu**
- Card unter `/ultimatecontrol_panel/ultimatecontrol-panel.js` (ohne Login, da
  Dashboard-Ressourcen als JavaScript-Modul geladen werden)
- `entry_id` ist optional; akzeptiert Config-Entry-ID, `unique_id` des Geräts
  (z. B. `415204`) oder einen Teil des Namens
- Websocket-Befehl `ultimatecontrol/devices`
- Service `ultimatecontrol.import_folder`

**Einbau**
1. HACS → UltimateControl C64 → Update auf 0.4.1
2. Home Assistant neu starten
3. Dashboard-Ressource: `/ultimatecontrol_panel/ultimatecontrol-panel.js?version=0.4.1`
   (Typ JavaScript-Modul)
4. Karte: `type: custom:ultimatecontrol-panel`, `entry_id` optional
